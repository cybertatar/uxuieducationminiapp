# UX-тренажёр

Telegram Mini App для UX/UI-дизайнеров: короткие тесты в трёх разделах.

- **UX:** эвристики Нильсена, законы UX, UX-райтинг, юзабилити-тестирование.
- **Гайдлайны:** Apple HIG, Material Design 3, доступность (WCAG 2.2).
- **Figma:** компоненты, свойства и варианты, автолейаут, переменные, дизайн-системы.

- **Вопросы с картинками.** Найди проблему на макете, выбери лучший из двух вариантов, узнай паттерн по картинке.
- **Разбор каждой ошибки.** Короткая суть, пример «как правильно» и ссылка на первоисточник (NN/g, Laws of UX, Apple, Google, W3C).
- **Повторение.** Вопросы, в которых ты ошибся, вернутся через 1, 3 и 7 дней.
- **Стрик.** Занимайся каждый день, а кот Кегль присмотрит за прогрессом.
- **Вопрос дня в чате.** По желанию бот пришлёт один вопрос в удобное время. Время, напоминания и паузу можно настроить в `/settings`.

Проект некоммерческий и делается для дизайн-сообщества. Нашли неточность в вопросе или хотите предложить свой — создайте issue.
