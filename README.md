# UX-тренажёр — Telegram Mini App

Образовательный проект для UX/UI-дизайнеров: короткие тесты по эвристикам Нильсена и законам UX.
При ошибке приложение показывает разбор и ссылки на первоисточники (NN/g, Laws of UX).

**Что есть в MVP**

- Два трека: «Эвристики Нильсена» (30 вопросов) и «Законы UX» (32 вопроса), часть вопросов с картинками-мокапами
- Сессии по 10 вопросов: сначала новые, потом те, где были ошибки
- Повторение ошибок с интервалами 1 → 3 → 7 дней
- Стрик как в Duolingo: день засчитывается за сессию в приложении или за ответ на вопрос дня в боте
- Бот с вопросом дня и напоминанием о стрике. Всё настраивается (`/settings` в боте или экран «Уведомления» в приложении): время, часовой пояс, пауза на 7 дней. По умолчанию бот не шлёт вопросы, пока пользователь сам не выберет время.

## Стек

Всё работает на бесплатном тарифе Cloudflare и живёт в одном воркере:

| Часть | Технология |
|---|---|
| Mini App | React + Vite, нативная тема Telegram (`web/`) |
| API и бот | Cloudflare Worker: Hono + grammY (`src/`) |
| База | Cloudflare D1 (SQLite) (`migrations/`) |
| Рассылки | Cron Trigger раз в минуту |
| Контент | TypeScript-файлы в `content/` |

## Локальная разработка

```bash
npm install
cp .dev.vars.example .dev.vars   # DEV_AUTH=1 пускает в API без Telegram
npm run dev                      # API на :8787, фронтенд на :5173
```

Откройте http://localhost:5173: приложение заработает под тестовым пользователем.
Боту нужен настоящий токен и публичный адрес, поэтому его удобнее проверять после деплоя.

```bash
npm test            # логика стриков, повторений, часовых поясов, авторизации и проверка контента
npm run typecheck
```

## Деплой (один раз)

1. **Бот.** В [@BotFather](https://t.me/BotFather): `/newbot` → сохраните токен.
2. **Cloudflare.** Зарегистрируйтесь на cloudflare.com (бесплатно), затем:
   ```bash
   npx wrangler login
   npx wrangler d1 create ux-quiz           # скопируйте database_id в wrangler.toml
   npx wrangler secret put BOT_TOKEN
   npx wrangler secret put WEBHOOK_SECRET   # любая длинная строка из букв, цифр, _ и -
   npm run deploy
   ```
3. Пропишите в `wrangler.toml` → `WEBAPP_URL` адрес, который выдал деплой (`https://ux-quiz.<ваш-аккаунт>.workers.dev`), и выполните `npm run deploy` ещё раз.
4. Откройте в браузере `https://<адрес>/bot/setup?secret=<WEBHOOK_SECRET>`. Это подключит вебхук, команды и кнопку меню.
5. В BotFather: `/newapp` (или Bot Settings → Configure Mini App) → укажите тот же URL.

Последующие обновления: `npm run deploy`.

## Как добавить вопрос

Вопросы лежат в `content/heuristics.ts` и `content/ux-laws.ts`:

```ts
{
  id: 'h-031',                 // уникальный и неизменный: по нему хранится прогресс
  track: 'heuristics',
  topic: 'Видимость состояния системы',
  text: 'Текст вопроса',
  image: '/images/h-something.svg', // необязательно, файл в web/public/images
  options: ['Правильный', 'Неправильный 1', 'Неправильный 2', 'Неправильный 3'],
  correct: 0,                  // индекс правильного варианта; при показе варианты перемешиваются
  explanation: 'Почему так — 2–3 предложения',
  links: [{ title: 'NN/g: ...', url: 'https://...' }],
}
```

`npm test` проверит, что id уникальны, индексы корректны, картинки существуют, а у каждого вопроса есть разбор и ссылка.
Вопросы с картинками в бот не попадают (Telegram не отправляет SVG), они есть только в приложении.
