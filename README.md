# UX-тренажёр

Telegram Mini App для UX/UI-дизайнеров: больше 1000 коротких вопросов по 14 темам в трёх разделах.

- **UX/UI:** эвристики Нильсена, законы UX, UX-райтинг, юзабилити-тестирование, визуальный дизайн.
- **Гайдлайны:** Apple HIG, Material Design 3, доступность (WCAG 2.2).
- **Figma:** компоненты, свойства и варианты, автолейаут, переменные, прототипирование, дизайн-системы.

- **Учебник.** 93 урока по всем 14 темам простым языком для новичков: пересказ статей NN/g, Laws of UX, Apple, Google, W3C и справки Figma с примерами из жизни, а в конце — три вопроса на закрепление. Из ошибок в тестах можно сразу перейти в нужный урок.
- **Задания на макетах.** Тапни на проблему, найди все ошибки на экране, выбери лучший из вариантов, расставь шаги по порядку, отметь все верные ответы.
- **Разбор каждого ответа.** Короткая суть, пример «как правильно» и ссылка на первоисточник (NN/g, Laws of UX, Apple, Google, W3C, справка Figma).
- **Повторение.** Вопросы, в которых ты ошибся, вернутся через 1, 3 и 7 дней.
- **Стрик.** Занимайся каждый день, а кот Кегль присмотрит за прогрессом.
- **Вопрос дня в чате.** По желанию бот пришлёт один вопрос в удобное время. Время, напоминания и паузу можно настроить в `/settings`.

Проект некоммерческий и делается для дизайн-сообщества. Нашли неточность в вопросе или хотите предложить свой — создайте issue.
