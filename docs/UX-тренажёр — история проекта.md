## 💡 Идея

Дизайнеры много читают NN/g, Apple HIG и Material, но редко проверяют, что запомнилось. Решение: **5 минут практики в день прямо в Telegram**, без установки приложения.

## ✨ Что умеет

- **5 тем (треков):** эвристики Нильсена, законы UX, Apple HIG, Material Design 3, доступность (WCAG 2.2 AA).
- **267 вопросов**, около четверти — с картинками.
- **Три формата вопросов:**
  1. Обычный — варианты текстом, опционально картинка-сценарий.
  2. Ответы-картинки (`image-choice`) — A/B (друг под другом) или сетка 2×2.
  3. «Тапни на проблему» (`hotspot`) — найти ошибку прямо на макете.
- **Разбор после каждого ответа** (и верного, и неверного): суть в одну строку, объяснение, картинка «как правильно», ссылка на первоисточник.
- **Интервальное повторение:** ошибки возвращаются через 1, 3 и 7 дней.
- **Стрик** — занимаешься каждый день, кот следит за прогрессом.
- **Бот:** вопрос дня в чате в удобное время, напоминание о стрике, пауза, настройки в `/settings`. Вопросы с картинками бот в чат не шлёт — только в приложении.
- Сессии по 10 вопросов.

## 🛠 Стек и архитектура

Всё в одном Cloudflare Worker, на **бесплатном тарифе**.

| Часть | Технология |
|---|---|
| Mini App (фронт) | React 19 + Vite, нативная тема Telegram — `web/` |
| API + бот | Cloudflare Worker: Hono + grammY — `src/` |
| База | Cloudflare D1 (SQLite) — `migrations/` |
| Рассылки | Cron Trigger раз в минуту (вопрос дня, напоминания) |
| Контент | TypeScript-файлы — `content/` |
| Тесты | Vitest — `tests/` |
| Деплой | GitHub Actions → Cloudflare при пуше в `main` |

### Структура репо

```
content/      вопросы и треки
src/          воркер: api.ts (REST для Mini App), bot.ts (бот и рассылки),
              streak.ts, review.ts, select.ts — чистая логика с тестами
web/          Mini App
  src/illustrations/  вайрфреймы, рисуются кодом (kit.ts — детали)
  src/Cat.tsx         пиксельный кот Кегль (1 символ = 1 пиксель)
  src/carousel/       слайды для Instagram
  gallery.html        все иллюстрации на одной странице
migrations/   схема D1 (users, answers, activity)
brand/        аватарки бота, слайды карусели, текст поста
scripts/      render-carousel.mjs — PNG карусели через Playwright
tests/        content / logic / effects
docs/DEVELOPMENT.md
```

### База данных (D1)
- `users` — Telegram id, часовой пояс (по умолчанию Europe/Moscow), настройки уведомлений (вопрос дня 10:00, напоминание 20:00, пауза), стрик.
- `answers` — прогресс по каждому вопросу: попытки, `box` (ступень повторения), `due_date`.
- `activity` — дни активности для стрика.

### Секреты и переменные
- GitHub Secrets: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `BOT_TOKEN`, `WEBHOOK_SECRET`.
- `wrangler.toml`: `WEBAPP_URL`, `database_id` (при деплое CI сам находит/создаёт базу `ux-quiz`).
- Локально: `.dev.vars` (`DEV_AUTH=1` пускает в API без Telegram).

## 🧠 Продуктовые решения и выводы

Итерации после живых тестов (хорошо для кейса в портфолио):

- **От «простыней текста» → к вопросам на макетах.** Дизайнеры думают картинками — визуальные форматы (A/B, сетка, hotspot) проверяют насмотренность, а не память на формулировки.
- **От мелких A/B рядом → к вариантам на всю ширину.** На телефоне половина ширины съедает детали.
- **От разбора только при ошибке → к разбору после любого ответа.** Угаданный ответ тоже надо закрепить.
- **Своя кнопка вместо нативной MainButton** — предсказуемый вид на iOS и Android, учёт safe area.
- **Полноэкранный режим** — больше места под контент, выглядит как нативное приложение.
- **Иллюстрации кодом, а не картинками** — автоматически подстраиваются под тему Telegram, легко добавлять новые.
- **Числа в текстах считаются из контента** (приветствие бота, карусель) — тексты не устаревают.
- Все факты сверены с первоисточниками (NN/g, Laws of UX, developer.apple.com, m3.material.io, w3.org).

## 🐞 Грабли (на будущее)

- В React-эффектах **никогда не возвращать результат вызова** (`() => fn()` → `() => { fn() }`). Есть тест `tests/effects.test.ts`.
- Неразрывного пробела мало, чтобы стрелка ↗ не отрывалась — нужен `white-space: nowrap` на хвосте ссылки.
- `requestWriteAccess` нельзя вызывать повторно, пока ждёт ответа первый вызов.
- После деплоя новой версии воркера нужно несколько секунд, прежде чем дергать `/bot/setup` (в CI есть ретраи).
- Аватарку бота можно поставить только вручную: @BotFather → `/setuserpic`.

### Как добавить вопрос
В нужный файл `content/*.ts`:
```ts
{
  id: 'h-040',            // уникальный и неизменный — по нему хранится прогресс
  track: 'heuristics',
  topic: 'Видимость состояния системы',
  image: 'h-pay-double',  // опционально
  text: 'Текст вопроса',
  options: ['Правильный', 'Неправильный 1', 'Неправильный 2', 'Неправильный 3'],
  correct: 0,             // варианты перемешиваются при показе
  summary: 'Суть в одну строку',
  explanation: 'Полный разбор',
  fix: 'h-pay-loading',   // опционально: картинка «как правильно»
  links: [{ title: 'NN/g: ...', url: 'https://...' }],
}
```
`kind: 'image-choice'` — `options` это ключи иллюстраций; `kind: 'hotspot'` — `image` + `zone`. `npm test` проверит id, индексы, иллюстрации, зоны и наличие разбора и ссылки.
